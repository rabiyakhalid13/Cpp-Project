# 🛒 Allergy Safe Product Finder (C++)

## About the Project

This project was developed during my first semester while learning the fundamentals of C++ programming.

The idea behind this project is to help users find products that are safe according to their allergies. The program takes a user's allergy information, compares it with the ingredients of different products stored in a file, and displays only the products that are safe to use.

Although it was an academic project, it gave me practical experience in solving real-world problems using basic programming concepts.

---

## Features

- Register a user with name and age
- Record multiple allergies
- Read product data from a text file
- Compare product ingredients with user allergies
- Display only allergy-safe products
- Generate a summary report
- Save the user's profile to a file
- Basic input validation
